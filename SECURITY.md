# Security Policy

## Reporting a vulnerability
**Please do not open a public issue for security problems.**

- **Team members:** report it privately to an organization owner right away, with steps to reproduce and the affected repository.
- **External researchers:** reach us through the contact details on [pulsetechltd.com](https://pulsetechltd.com) with the subject *Security*.

We aim to acknowledge reports within 3 business days and will keep you informed until it is resolved.

## Leaked credentials
If a secret (API key, password, token, `.env` file) is committed or shared by mistake:
1. Tell an organization owner immediately.
2. Rotate the credential — removing it from git history is not enough.
3. Check access logs for misuse.

## Supported versions
Only the latest deployed version of each product receives security fixes.
